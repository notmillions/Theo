# Theo

Theo est une application mobile Flutter conçue pour piloter un drone et suivre ses données de vol via Bluetooth. Le projet comprend également un firmware Arduino pour communiquer avec les moteurs et les capteurs embarqués.

L’application est développée en Dart et le firmware en C++ pour Arduino.

Le code de l’application, les dépendances et les instructions d’installation se trouvent dans le dossier [drone_app](drone_app/README.md).

Dépôt : https://github.com/notmillions/Theo
